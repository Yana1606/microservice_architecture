## Границы проверки

2PC — явно обозначенная учебная модель на прикладных резервированиях, с координатором и двумя владельцами отдельных SQLite в одном консольном процессе. Это не XA/DTC и не распределённый коммит SQLite; в основной турнир он не включён. Пауза доставки в CAP-сценарии моделирует недоступный канал на отправителе и сохраняет сообщения в outbox; firewall не перенастраивается.

Docker Engine на машине отсутствует. Compose получил healthchecks; YAML и настройки проверяются статически. Контейнерная сборка/запуск здесь не выполнялись. GitHub Actions настроен на сборку, тесты, лимит файлов и запуск Compose, но до push его удалённый результат неизвестен. Нагрузочные испытания и реальная система жюри/QR не входят в эту лабораторную; team/checking остаются отдельным имитатором по заданию.
